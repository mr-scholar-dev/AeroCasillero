# Form1

## Objetivo
`Form1` funciona como pantalla principal de prueba del sistema Aero-Casillero.

## Funciones

- registrar clientes
- mostrar clientes en una tabla
- abrir el formulario de paquetes
- abrir el formulario de casilleros

## Qué valida

- nombres del cliente
- apellidos del cliente
- cédula o pasaporte
- correo
- teléfono
- casillero asignado

## Qué muestra

- encabezado principal
- formulario de captura de clientes
- lista de clientes registrados

## Para qué sirve en el proyecto

Sirve como punto de entrada visual para probar la arquitectura por capas:

- UI
- BLL
- DAL

También permite demostrar que la aplicación ya tiene una base funcional de trabajo.
